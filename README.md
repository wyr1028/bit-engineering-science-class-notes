# 北京理工大学 · 工程科学实验班（2024级）知识库

> 基于教务系统「培养方案 · 执行计划」整理的课程知识框架。
> 采用 Obsidian 管理，**领域 → 课程** 两级树状结构，每门课程为一个节点。

## 结构

```
├── 01 学分与毕业要求.md      学分统计（不参与知识图谱）
├── 领域/     8 个知识领域（树根）
└── 课程/    45 门课程（每门一个节点）
```

## 笔记内容

每门课程节点包含：

- **YAML 元数据**：名称 / 学分 / 总学时 / 考核方式 / 课程属性 / 课程性质 / 开课单位 / 领域
- **分章大纲**：`### 第N章 …`
- **知识点 + 公式 + 完整推导**：LaTeX 公式（`$…$` / `$$…$$`），尽可能给出逐步推导、物理意义与典型应用

## 使用

用 [Obsidian](https://obsidian.md) 打开本仓库目录即可（数学公式在阅读视图下渲染）。
打开 Graph View 可见 8 棵以领域为根的树。
